Formal Verification of Parity Obstructions and Fixed-Point Exclusions for Proper-Divisor Moments (OEIS A245211) in Lean 4

Fixed points with at most six prime factors, counted with multiplicity

Mar Allen P. Sugui mariyaholic.github.io · github.com/mariyaholic November 22, 2026 MSC 2020 11A25, 68V20 / 11Y70, 11D61 leanprover/lean4:v4.35.0 PDF · LaTeX source

Abstract

Jaroslav Krizek conjectured that 21 is the only positive integer equal to the sum a(n) of d τ(d) over its proper divisors d, where τ(d) counts positive divisors. We prove in Lean 4.35.0 that 21 is the only fixed point with Ω(n)≤ 6, counting prime factors with multiplicity. For a squarefree product of k primes, a fixed point would satisfy ∏p∣ n(2p+1)=(2k+1)n. At k=5 and k=6, dominance and growth bounds leave 14 and 30 candidates for the least prime, respectively. Factoring successive terms 2p+1 excludes every candidate. For repeated primes we use exact-exponent parity, dominance bounds and congruences. Across eight modules we also certify the first 66 terms of OEIS A245211, the minima 72 and 144 of A245213 and A245214, and uniqueness through n=150. A separate Python sieve finds only 21 through 106. Whether a fixed point coprime to 6 with Ω(n)≥ 7 exists remains open.

1. Problem Statement and Scope of the Formalization

For a positive integer n, let τ(n) = ∑d | n 1 (OEIS A000005 [8]) and σ(n) = ∑d | n d (OEIS A000203 [9]) denote the classical divisor-count and divisor-sum functions [1, 2, 19]. Gabdullin, Iudelevich and Luca study the number of distinct values of n τ(n) [5]. Noppakaew and Pongsriiam study injectivity for products of polynomials and arithmetic functions, including n τ(n) [7]. Summing this weight over all divisors gives the full first moment

S(n) = ∑d | n d τ(d) = (id · τ * 1)(n)

(OEIS A060640 [12]). Because d ↦ d τ(d) is multiplicative, S(n) is multiplicative and takes the prime-power values

S(pe) = 1 + ∑j=1e (j + 1) pj,   S(p) = 2p + 1.

On July 23, 2014, Jaroslav Krizek introduced sequence A245211 in the On-Line Encyclopedia of Integer Sequences [13] as the proper-divisor restriction of S(n):

a(n) = ∑d | n, d < n d τ(d) = S(n) − n τ(n),

where n τ(n) is OEIS A038040 [11]. On the same date, Krizek introduced three companion sequences measuring the balance between the top term n τ(n) and the proper-divisor sum a(n):

A245212(n) = n τ(n) − a(n) = 2n τ(n) − S(n) [14],
A245213 = {n ≥ 1 | A245212(n) < n} = {72, 96, 120, 144, 180, …} [15],
A245214 = {n ≥ 1 | A245212(n) < 0} = {144, 192, 216, 240, 288, …} [16].

At n = 21 = 3 · 7, the proper divisors are 1, 3, 7, giving

a(21) = 1 · τ(1) + 3 · τ(3) + 7 · τ(7) = 1 · 1 + 3 · 2 + 7 · 2 = 21.

Krizek observed in [13] that a(p) = 1 for every prime p, that a(2p) = 2p + 5 for every odd prime p, that n = 144 is the smallest integer with n τ(n) < a(n), and that n = 21 is the only known solution to a(n) = n. In the Google DeepMind Formal Conjectures repository [4], FormalConjectures/OEIS/245211.lean states the uniqueness of n = 21 as an open target alongside five decide evaluations a(1) through a(5).

2. Summation Primitives, OEIS Identities, and Refutation Checks

To evaluate divisor sums inside the Lean 4.35.0 [3] kernel without exceeding the default maximum recursion depth (maxRecDepth = 1024), OeisA245211/Basic.lean defines the range sum sumUpTo f k = ∑i=1k f(i) via a balanced binary-tree recursion sumRangeBin f fuel a len of depth 16 (216 = 65,536), and proves its exact equivalence (sumRangeBin_eq_sumRangeLinear) with the linear recurrence sumRangeLinear. This yields the definitional and [simp] step equations (sumUpTo_zero, sumUpTo_succ):

sumUpTo f 0 = 0,   sumUpTo f (k + 1) = sumUpTo f k + f(k + 1).

Using the decidable positive divisibility predicate dividesB d n := (0 < d) ∧ (n mod d == 0), we define weighted divisor sums up to k:

sumDivUpTo n w k := sumUpTo (λd ⇒ if dividesB d n then w(d) else 0) k,

with sumDiv n w := sumDivUpTo n w n and sumProperDiv n w := sumDivUpTo n w (n − 1).

Definition 2.1 (Arithmetic Functions and Companion Predicates; Basic.lean).

For n ∈ N, we define the divisor-count, divisor-sum, and proper-divisor moment functions [8, 9, 11–14] tau n := sumDiv n (λ_ ⇒ 1), sigma n := sumDiv n (λd ⇒ d), nTau n := n · tau n, fullMoment n := sumDiv n (λd ⇒ d · tau d), a n := sumProperDiv n (λd ⇒ d · tau d), and cantileverDiff n := (nTau n : Z) − (a n : Z), together with the decidable predicates IsFixedPoint n := 0 < n ∧ a n = n, IsInA245213 n := 0 < n ∧ cantileverDiff n < (n : Z) [15], and IsInA245214 n := 0 < n ∧ cantileverDiff n < 0 [16].

Theorem 2.2 (OEIS Identities and Divisor-List Equivalences; Basic.lean).

For every n ∈ N:

  1. (fullMoment_eq_a_add_nTau, a_eq_fullMoment_sub_nTau) Whenever 0 < n, Krizek's additive identity [13] gives fullMoment n = a n + nTau n and a n = fullMoment n − nTau n.
  2. (a_int_eq_nTau_sub_cantileverDiff) By the cantilever difference definition [13, 14], (a n : Z) = (nTau n : Z) − cantileverDiff n.
  3. (isInA245214_iff, isInA245213_iff) For the companion sequences [15, 16], we have IsInA245214 n ⇔ 0 < n ∧ nTau n < a n and IsInA245213 n ⇔ 0 < n ∧ nTau n < a n + n, so IsInA245214 n ⇒ IsInA245213 n (isInA245213_of_isInA245214).
  4. (isFixedPoint_iff_fullMoment) IsFixedPoint n ⇔ 0 < n ∧ fullMoment n = n · (tau n + 1).
  5. (mem_divisors_iff, mem_properDivisors_iff) We have d ∈ divisors n ⇔ 1 ≤ d ≤ n ∧ d | n, and for 0 < n, d ∈ properDivisors n ⇔ 1 ≤ d < n ∧ d | n; both lists are duplicate-free (divisors_nodup, properDivisors_nodup).
  6. (tau_eq_length_divisors, a_eq_sumList_properDivisors) For every n ∈ N, tau n = (divisors n).length and a n = sumList (properDivisors n) (λd ⇒ d · tau d).

Refutation Check 2.3 (Basic.lean, TableCerts.lean).

  1. (not_isFixedPoint_0–not_isFixedPoint_33, not_isFixedPoint_725) The boundary input n = 0 (0 < n fails), unit n = 1 (a(1) = 0), primes n = 2, 3 (a(p) = 1), even numbers n = 4, 6 (a(4) = 5, a(6) = 11), odd prime squares n = 9, 25 (a(9) = 7, a(25) = 11), odd semiprimes n = 15, 33 (a(15) = 17, a(33) = 29), and the near-miss n = 725 = 52 · 29 (a(725) = 724) all satisfy ¬IsFixedPoint n.
  2. (not_isInA245213_71, isInA245213_72, not_isInA245214_72, not_isInA245214_143, isInA245214_144) At n = 71, ¬IsInA245213 71 holds; at n = 72, IsInA245213 72 holds (cantileverDiff 72 = 62 < 72) while ¬IsInA245214 72 holds (62 ≮ 0), strictly separating A245213 from A245214; and at n = 143 and 144, ¬IsInA245214 143 and IsInA245214 144 (cantileverDiff 144 = −66 < 0) hold.
  3. (properDivisors_21, a_21, isFixedPoint_21) At n = 21, properDivisors 21 = [1, 3, 7], a 21 = 21, and IsFixedPoint 21.

3. The Fundamental Dominance Inequality and Parity Exclusions

Because every term d τ(d) in a(n) is nonnegative, sampling any two distinct proper divisors 1 < m < n of n gives a lower bound on a(n) without requiring the prime factorization of n. In OeisA245211/Dominance.lean, we prove general point-sampling lower bounds for sumUpTo (le_sumUpTo, add_le_sumUpTo, add_three_le_sumUpTo) and deduce lower bounds on τ(m) and a(n).

Lemma 3.1 (Divisor-Count Lower Bounds; Dominance.lean).

  1. (tau_pos) For every n > 0, 1 ≤ tau n.
  2. (tau_ge_two) For every m > 1, 2 ≤ tau m since 1 and m are distinct divisors of m.
  3. (tau_ge_three_of_proper_divisor) If m has a proper divisor 1 < d < m with d | m, then 3 ≤ tau m since 1 < d < m all divide m.
  4. (a_ge_one_add_properDiv) If 1 < d < n and d | n, then 1 + d · tau d ≤ a n.

Theorem 3.2 (Fundamental Dominance Theorem; Dominance.lean).

Suppose n = k · m with 1 < k, 1 < m, and k ≤ tau m. By gt_self_of_dvd_le_tau, the proper divisors 1 and m of n force

a n ≥ 1 + m · tau m ≥ 1 + k · m = n + 1 > n,

and in particular ¬IsFixedPoint n (not_isFixedPoint_of_dvd_le_tau).

Proof. Both 1 and m are proper divisors of km, and m>1 makes them distinct. Their contributions give a(n)≥1+m τ(m)≥1+mk=n+1.

Corollary 3.3 (Unconditional Even and Composite-Multiple-of-3 Exclusions; Dominance.lean).

  1. (a_two_mul_ge, a_gt_self_of_even_gt_two) For every m ≥ 2, a(2m) ≥ 2m + 1. Equivalently, every even integer n > 2 satisfies a n ≥ n + 1 > n.
  2. (ne_self_of_even, not_isFixedPoint_of_even, odd_of_isFixedPoint) Since a 2 = 1 ≠ 2, no positive even integer satisfies a n = n. Every fixed point of OEIS A245211 is odd (n mod 2 = 1).
  3. (a_three_mul_ge_of_proper_divisor) Whenever m has a proper divisor 1 < d < m with d | m, Lemma 3.1(3) gives tau m ≥ 3, so a(3m) ≥ 3m + 1 > 3m and ¬IsFixedPoint (3m) (not_isFixedPoint_three_mul_of_proper_divisor).

4. Primes, Prime Powers, Semiprimes, Multiples of 3, and Three-Prime Families

In OeisA245211/Families.lean, we define arithmetic primality IsPrime p := 2 ≤ p ∧ (∀d, d | p → d = 1 ∨ d = p) and establish support-reduction lemmas for sumUpTo when the summand is supported at {1} (sumUpTo_eq_single), {1, a} (sumUpTo_eq_pair), or {1, a, b} (sumUpTo_eq_triple), or when all terms with d > 1 vanish modulo p (sumUpTo_mod_eq_first).

Theorem 4.1 (Primes and Prime Powers; Families.lean).

Let p ∈ N.

  1. (tau_of_isPrime, isPrime_iff_tau_eq_two) By the divisor-count characterization of primes [1, Ch. 2; 2, Ch. 6], IsPrime p ⇔ 2 ≤ p ∧ tau p = 2. This equivalence equips IsPrime p with a decidable instance (instDecidableIsPrime).
  2. (a_of_isPrime, a_lt_self_of_isPrime) For every prime p, a p = 1 < p (Krizek's first 2014 OEIS formula [13]), so ¬IsFixedPoint p (not_isFixedPoint_of_isPrime).
  3. (a_prime_pow_mod_p, ne_self_of_prime_pow) For every prime p and exponent k ≥ 1, every divisor d > 1 of pk is a multiple of p (dvd_of_dvd_prime_pow). Consequently, every proper-divisor term d · tau d with d > 1 is divisible by p, giving a(pk) mod p = 1 ≠ 0 = pk mod p, and therefore a(pk) ≠ pk and ¬IsFixedPoint (pk) (not_isFixedPoint_prime_pow).

Next, using Euclid's prime divisibility lemma (coprime_or_dvd_of_isPrime) [1, Ch. 1; 2, Ch. 2], we classify all divisors of a product of two primes p · q (dvd_mul_primes) and all proper divisors when p < q (proper_dvd_mul_primes: d ∈ {1, p, q}), obtaining the closed-form semiprime formula and unconditional fixed-point uniqueness across all semiprimes and all multiples of 3.

Theorem 4.2 (Semiprime Formula and Uniqueness Among Semiprimes and Multiples of 3; Families.lean).

  1. (a_semiprime) For primes p < q, the proper divisors of pq are 1, p, q, each prime divisor having τ = 2, so a(pq) = 1 + 2p + 2q.
  2. (a_two_mul_odd_prime, a_three_mul_prime) For every prime p > 2, a(2p) = 2p + 5 (Krizek's second 2014 OEIS formula [13]), and for every prime p > 3, a(3p) = 2p + 7.
  3. (semiprime_fixedPoint_iff) For any primes p ≤ q, IsFixedPoint (pq) ⇔ p = 3 ∧ q = 7.
  4. (three_dvd_fixedPoint_iff_eq_21) For every n ∈ N divisible by 3, IsFixedPoint n ⇔ n = 21.

Proof. For p=q, the prime-power exclusion applies. For p<q, the equation becomes (p-2)(q-2)=5, whose ordered positive factors are 1 and 5 (semiprime_diophantine_eq). This gives p=3 and q=7. For a multiple n=3m, the case m=0 fails positivity and m=1 gives a(3)=1. If m is composite, exists_proper_divisor_of_not_isPrime gives a divisor strictly between 1 and m, so Corollary 3.3 gives a(3m)>3m. A prime cofactor reduces to the semiprime calculation.

Theorem 4.3 (Three-Prime-Factor Identities and Exclusions; Families.lean).

  1. (p2q_near_miss_identity, odd_p2q_formula_ne_self) For distinct primes p ≠ q, the proper divisors of p2q are 1, p, p2, q, pq, whose τ-weighted sum is the polynomial 1 + 2p + 3p2 + 2q + 4pq. For all p, q ∈ N with p ≥ 5 and q ≥ 3,
    (p2 − 4p − 2)(q − 3) + (1 + 2p + 3p2 + 2q + 4pq) = p2q + 7(2p + 1),
    and whenever p mod 2 = 1 and q mod 2 = 1, 1 + 2p + 3p2 + 2q + 4pq is even whereas p2q is odd, so they are never equal.
  2. (three_prime_moment_ne) For all primes p < q < r, the product (2p + 1)(2q + 1)(2r + 1) (which equals S(pqr) by Theorem 5.1(1)) satisfies
    (2p + 1)(2q + 1)(2r + 1) ≠ 9 p q r.

Proof. For p≥11 the ordered primes are at least 11, 13 and 17. The product of the three ratios 2+1/x is at most 21735/2431<9 (three_prime_growth_bound). For p=2 the two sides have opposite parity. For p=3, divisibility forces one of the other primes to be 7, leaving 15(2x+1)=27x for the remaining prime. For p=5, one prime must be 11, leaving 23(2x+1)=45x. Both equations are impossible for positive x. For p=7, the factor 5 would have to divide one of the larger primes.

5. Multiplicativity, General Parity Obstruction, and Sharpened Dominance

In OeisA245211/Parity.lean, we prove that τ and S are multiplicative on coprime arguments, derive the exact prime-power parity congruence, and establish two structural obstructions for general fixed points.

Theorem 5.1 (Multiplicativity and Odd Prime-Power Parity; Parity.lean).

Let a, b, p, e ∈ N with gcd(a, b) = 1, 0 < a, 0 < b, and p prime.

  1. (tau_mul_of_coprime, fullMoment_mul_of_coprime) Both τ and the Dirichlet convolution moment S = fullMoment [1, Ch. 2; 2, Ch. 6; 12] are multiplicative on coprime arguments: τ(ab) = τ(a) τ(b) and S(ab) = S(a) S(b).
  2. (tau_prime_pow, fullMoment_prime_pow_succ) On prime powers [2, Ch. 6; 19, Ch. 3], τ(pe) = e + 1 and S(pe+1) = S(pe) + (e + 2) pe+1.
  3. (fullMoment_prime_pow_mod_two, fullMoment_prime_pow_odd_iff) When p is odd (p mod 2 = 1), S(pe) mod 2 = ((e + 1)(e + 2)/2) mod 2, so S(pe) is odd if and only if e ≡ 0 (mod 4) or e ≡ 1 (mod 4).

Theorem 5.2 (General Parity Obstruction and Sharpened Dominance; Parity.lean).

Suppose IsFixedPoint n holds.

  1. (exact_exponent_mod_four_of_isFixedPoint, not_isFixedPoint_of_exact_exponent_mod_four_ge_two) If τ(n) is even (tau n mod 2 = 0, i.e., n is not a square [2, Ch. 6; 19, Ch. 3]) and pe ∥ n for a prime p, then S(n) = n(τ(n) + 1) is odd, so S(pe) is odd and e ≡ 0 or 1 (mod 4). Every prime-power exponent with e ≡ 2, 3 (mod 4) is excluded whenever τ(n) is even.
  2. (sharpened_dominance_bound, exact_prime_pow_tau_lt_prime) If n = pem with p prime, gcd(pe, m) = 1, 1 ≤ e, and 1 < m, then factoring n = p · (pe−1m) with τ(pe−1m) = e τ(m) and applying Theorem 3.2 (not_isFixedPoint_of_dvd_le_tau) to the proper divisors 1 and pe−1m forces e τ(m) < p.

6. Classification by Prime-Factor Multiplicity

In OeisA245211/OmegaFour.lean, we define omegaBig n = Ω(n) (OEIS A001222 [10]), prove Ω(pm) = 1 + Ω(m) for prime p and positive m (omegaBig_prime_mul), additivity on positive factors (omegaBig_mul) and sorted prime-list decomposition (exists_primes_of_omegaBig) [1, Ch. 1; 2, Ch. 3], and close all Ω(n) ≤ 4 cases.

Theorem 6.1 (Complete Ω(n) ≤ 4 Classification; OmegaFour.lean).

  1. (not_isFixedPoint_prime_cube_mul_prime, not_isFixedPoint_prime_sq_mul_two_primes) For distinct primes p, q, r, neither p3q (τ = 8, ep = 3) nor p2qr (τ = 12, ep = 2) is a fixed point, by Theorem 5.2(1).
  2. (p2q2_diophantine_ne, not_isFixedPoint_prime_sq_mul_prime_sq) For all distinct primes p ≠ q, p2q2 is never a fixed point: modulo 5, the polynomial 3x2 + 2x + 1 never vanishes for any x ∈ N (three_sq_add_two_mul_add_one_mod_five_ne_zero), so 5 ∤ (3p2 + 2p + 1)(3q2 + 2q + 1) whereas 5 | 10p2q2 for all p, q ∈ N (p2q2_diophantine_ne); moreover, for p ≥ 13 and q ≥ 17, (3p2 + 2p + 1)(3q2 + 2q + 1) < 10p2q2 (p2q2_growth_bound).
  3. (four_prime_moment_ne, not_isFixedPoint_four_distinct_primes) For primes 5 ≤ p < q < r < s, (2p + 1)(2q + 1)(2r + 1)(2s + 1) ≠ 17pqrs: for p ≥ 29, the growth bound four_prime_growth_bound holds, and each p ∈ {5, 7, 11, 13, 17, 19, 23} is eliminated by Cunningham-chain divisibility.
  4. (fixedPoint_eq_21_of_omegaBig_le_four, omegaBig_ge_five_of_isFixedPoint_ne_21) Every fixed point with Ω(n) ≤ 4 equals 21. Equivalently, every fixed point n ≠ 21 satisfies gcd(n, 6) = 1 and Ω(n) ≥ 5.

Theorem 6.2 (Ω(n) = 5 Reduction; OmegaFour.lean).

  1. (not_isFixedPoint_prime_four_mul_prime) For distinct primes p, q ≥ 5, p4q is never a fixed point: Theorem 5.2(2) forces p ≥ 11 and q ≥ 7, p4q_growth_bound closes p ≥ 31, and p ∈ {11, 13, 17, 19, 23, 29} fails exact divisibility.
  2. (omegaFive_must_be_squarefree_ge_17) Every fixed point with Ω(n) = 5 is squarefree of the form n = pqrst with primes 17 ≤ p < q < r < s < t.

For a squarefree fixed point with prime set P of size k, multiplicativity gives ∏x∈ P(2x+1)=(2k+1)n. If x∈ P and a prime f divides 2x+1 but does not divide 2k+1, then f must also belong to P. We call this step Cunningham forced closure. A forced prime below the least member of P contradicts its minimality.

Theorem 6.3 (Five distinct primes, OmegaFive.lean).

A squarefree product of five primes with least prime p≥17 cannot be fixed. Here 25+1=33=3·11. For p≥73, the ordered primes are at least 73,79,83,89,97. Since 2+1/x decreases with x, their product of ratios is strictly less than 33 (five_prime_growth_bound). For the 14 primes 17≤ p<73, prime_dvd_33pqrst_mem forces prime divisors other than 3 and 11 into the product, and prime_dvd_33pqrst_impossible excludes any such divisor below p. For example, p=23 forces 47, and 2·47+1=95 forces 5<23. The resulting inequality five_prime_moment_ne gives not_isFixedPoint_five_distinct_primes.

Combining this result with the repeated-prime cases gives not_isFixedPoint_of_omegaBig_eq_five and fixedPoint_eq_21_of_omegaBig_le_five. The corollary omegaBig_ge_six_of_isFixedPoint_ne_21 gives Ω(n)≥6 for any other fixed point.

Theorem 6.4 (Six prime factors with repetition, OmegaSix.lean).

A fixed point with six prime factors would have six distinct primes. Removing its least prime p would leave a divisor with 32 divisors, so dominance requires p>32 and primality gives p≥37 (omegaSix_must_be_squarefree_ge_37). Theorem 6.5 (Six distinct primes, OmegaSix.lean).

For six ordered primes with least prime p≥37, the moment equation is ∏x∣n, x prime(2x+1)=65n, with 65=5·13. Once p≥181, the six primes are at least 181,191,193,197,199,211. The product of the six ratios 2+1/x is then strictly less than 65 (six_prime_growth_bound). For each of the 30 remaining least primes, prime_dvd_65pqrstu_mem and prime_dvd_65pqrstu_impossible propagate prime factors outside {5,13} to a contradiction. For example, at p=37, the factor 3 of 2p+1=75 is already smaller than 37. The theorems six_prime_moment_ne and not_isFixedPoint_six_distinct_primes exclude the squarefree case.

Corollary 6.6 (Classification through six prime factors).

The theorem not_isFixedPoint_of_omegaBig_eq_six excludes every positive integer with exactly six prime factors. Hence fixedPoint_eq_21_of_omegaBig_le_six proves that every positive fixed point with Ω(n)≤6 equals 21. Since a(21)=21, this is a classification in both directions. For any other fixed point, omegaBig_ge_seven_of_isFixedPoint_ne_21 gives Ω(n)≥7 and gcd_six_eq_one_of_isFixedPoint_ne_21 gives gcd(n,6)=1.

The independent Python verifier uses two searches. Its five-prime hyperbolic search bounds the first three primes using the decreasing ratio 2+1/x. For a triple with D=pqr, N=(2p+1)(2q+1)(2r+1) and A=33D-4N>0, it factors 33DN to solve (As-2N)(At-2N)=33DN for the last pair. It examines 16 first primes, 340 pairs and 43,849 triples and finds zero solutions. It tests candidate primes with the first twelve prime bases of the Miller–Rabin test [6, 17, 18].

The forced-closure routine tests squarefree products for 3≤ k≤10. Given a candidate least prime, it repeatedly factors 2x+1 for each required prime x. It rejects the candidate if a required prime is smaller than the proposed least prime or if more than k distinct primes are required. For k=5 all 14 candidates fail. For k=6 the integer lower bound is 33, the first candidate prime is 37, and all 30 candidates fail. The script also checks the congruences and finite cases for repeated primes at k=6. The Lean classification uses its own proofs for every partition.
