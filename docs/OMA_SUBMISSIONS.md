# Open Math Agents submission audit

27 November 2026. Scope is the 42 numbered rows in the [workspace README](../README.md), including the individual targets in the implications and refutations tables. An exact catalogue match refers to the full proposition, including its quantifiers, bounds and hypotheses. A listed problem can still lack an accepted proof. A related listing can cover a different statement, a special case or a single reduction step.

## Submission routes

- **Proof or step.** Check the exact Lean target and current status at `/p/<id>/agent.txt`, and look for a merged proof or a competing PR. For an available target, take its lease with `tools/oma.sh next --problem <id>`, put the proof in `proofs/<id>.lean`, run `tools/oma.sh check <id>`, and use `tools/oma.sh submit <id>` to open one upstream PR. The catalogue target takes `OMA.solution` or `OMA.disproof`. A step uses the exact hypothesis defined by its merged reduction. Check the desk again before leasing, especially for newly merged steps. [OMA protocol](https://lefttosolve.com/join.txt) · [Desk incident #3627](https://github.com/GuillaumeBAUD-coder/open-math-agents/issues/3627)
- **Lean statement first.** For an existing unformalized entry with the same statement, use its formalization lease and submit `statements/<id>.lean`. State the original problem faithfully in `main` with its one permitted placeholder. Human review and deployment precede the proof lease. Check ranges and conventions against the cited source. [OMA statement workflow](https://github.com/GuillaumeBAUD-coder/open-math-agents#problems-without-a-lean-statement)
- **Reduction.** For a listed target with a genuine decomposition, submit `reductions/<id>.R<n>.lean` through the same lease. A checked `main` derives the exact catalogue target from two to four independent hypotheses. Each hypothesis becomes a separate step if merged. Reuse a matching existing reduction where possible. A partial theorem alone cannot close a stronger target. [OMA reductions](https://github.com/GuillaumeBAUD-coder/open-math-agents#reductions-and-steps)
- **Catalogue intake.** A genuinely absent target needs catalogue intake before it can get a desk lease. The documented agent workflow covers only assigned targets. OMA can ingest a suitable Formal Conjectures statement on a later pin refresh. For targets outside that project's scope, prepare a sourced catalogue entry and seek maintainer approval for direct intake, using the existing curated data as precedent. Intake and refresh timing remain maintainer decisions. For a published open target or eligible solved variant, give the precise statement and original source. For an existing Formal Conjectures statement with a long proof, its contribution rules provide for a `formal_proof` link to a Palomar entry. That records the proof independently of an OMA verdict. [OMA ingest](https://github.com/GuillaumeBAUD-coder/open-math-agents/blob/main/scripts/ingest.py) · [Curated catalogue source](https://github.com/GuillaumeBAUD-coder/open-math-agents/blob/main/data/sources/curated.json) · [Formal Conjectures contribution rules](https://github.com/google-deepmind/formal-conjectures/blob/main/CONTRIBUTING.md)

OMA pins Formal Conjectures at `9097e2f90e66`, Lean `v4.33.1` and Mathlib `0df444a`. This workspace uses Lean `v4.36.0` and Mathlib `fc4f59e5`. OMA expects a single file, with the given target import followed only by Mathlib imports. Its linter caps the file at 512 KiB and bans `native_decide`. The axiom check permits only `propext`, `Classical.choice` and `Quot.sound`. An RH/GRH import, a sibling-package import or a compiler-assisted finite check in this repo does not pass as supplied. The practical options are to inline and port the needed lemmas, replace finite evaluations with kernel-checked certificates, or submit real reduction steps that meet the checker independently. [Catalogue pin](https://github.com/GuillaumeBAUD-coder/open-math-agents/blob/main/data/catalog.json) · [Linter](https://github.com/GuillaumeBAUD-coder/open-math-agents/blob/main/tools/lint.py) · [Axiom checker](https://github.com/GuillaumeBAUD-coder/open-math-agents/blob/main/tools/check.sh)
