# Small generators, deterministic Solovay–Strassen and Miller's factoring under GRH in Lean

Bach (*Explicit bounds for primality testing and related problems*, Math. Comp. 55 (1990)
355–380) proved under ERH that a proper subgroup of `(ℤ/m)ˣ` omits a positive integer
`< 2 log² m` (his Theorem 2) and one prime to `m` below `3 log² m` (Theorem 3), and drew two
consequences (§6): a composite `m` has a compositeness witness "in the sense of Miller or
Solovay–Strassen" that is at most `2 log² m`, and `(ℤ/m)ˣ` is generated by the numbers less than
`3 log² m` that are prime to `m`. Miller (*Riemann's hypothesis and tests for primality*,
J. Comput. System Sci. 13 (1976) 300–317) showed under ERH that a multiple of Carmichael's
`λ(n)`, for instance `φ(n)`, lets small bases split `n`.

This project proves in Lean, from Bach's subgroup bound with constant `2` (proved under GRH in
[lls-grh](../lls-grh/)):

1. **Generators.** For every `m ≥ 1`, `(ℤ/m)ˣ` is generated by the classes of the positive
   integers `a ≤ 2 log² m` prime to `m`. This is Bach's §6 statement with his `3` replaced by
   `2`: lls-grh's `Ankeny.BachSubgroupBound 2` returns a unit, so it is Bach's Theorem 3 with
   the constant of his Theorem 2.
2. **Deterministic Solovay–Strassen.** Every odd composite `n` has a base `a ≤ 2 log² n`,
   prime to `n`, with `a^((n-1)/2) ≢ (a/n) (mod n)` (Jacobi symbol); and an executable test
   `solovayStrassenTest` is proved correct for every odd `n > 1`, the counterpart of
   miller-grh's `millerTest_iff_prime`. The test is that of Solovay and Strassen (*A fast
   Monte-Carlo test for primality*, SIAM J. Comput. 6 (1977) 84–85); the bound is Bach's.
3. **Miller's factoring reduction.** For odd `n > 1` not a prime power and any `M > 0` with
   `u^M = 1` for all units `u` mod `n`, write `M = 2^s t`, `t` odd: some base `a ≤ 2 log² n` and
   some `i ≤ s` make `gcd(a^(2^i t) − 1, n)` a proper factor of `n`.

`Unconditional/` proves all three unconditionally in Lean, with GRH supplied by the certified
proof in [leanprover-community/riemann-hypothesis](https://github.com/leanprover-community/riemann-hypothesis).

**Status in the literature: RH-consequence.** Each statement is a published consequence of
ERH (Bach 1990; Miller 1976). Unconditionally only power bounds are known for the least Euler
witness (Burthe, Acta Arith. 80 (1997), bound not re-read here). Whether a deterministic
polynomial-time factoring of a general `n` from `φ(n)` is known without ERH was not checked
(May 2004 and Coron–May 2007 treat `N = pq`).

with, in `BachCorollaries/Statement.lean`,

```lean
def GeneratorBound (c : ℝ) : Prop :=
  ∀ (m : ℕ) [NeZero m],
    Subgroup.closure {u : (ZMod m)ˣ |
      ∃ a : ℕ, 0 < a ∧ (a : ℝ) ≤ c * Real.log m ^ 2 ∧ (u : ZMod m) = a} = ⊤

def IsEulerProbablePrime (n a : ℕ) : Prop :=
  (a : ZMod n) ^ ((n - 1) / 2) = ((jacobiSym a n : ℤ) : ZMod n)

def SolovayStrassenStatement (c : ℝ) : Prop :=
  ∀ n : ℕ, Odd n → 1 < n → ¬ n.Prime →
    ∃ a : ℕ, 0 < a ∧ (a : ℝ) ≤ c * Real.log n ^ 2 ∧ a.Coprime n ∧ ¬ IsEulerProbablePrime n a

def MillerFactoringStatement (c : ℝ) : Prop :=
  ∀ n M : ℕ, Odd n → 1 < n → ¬ IsPrimePow n → 0 < M → (∀ u : (ZMod n)ˣ, u ^ M = 1) →
    ∃ a : ℕ, 0 < a ∧ (a : ℝ) ≤ c * Real.log n ^ 2 ∧
      ∃ i ≤ M.factorization 2,
        1 < Nat.gcd (a ^ (2 ^ i * (M / 2 ^ M.factorization 2)) - 1) n ∧
        Nat.gcd (a ^ (2 ^ i * (M / 2 ^ M.factorization 2)) - 1) n < n
```

## Proof outline

1. `BachCorollaries/Generators.lean` (`generators_of_bach`): if the small units generated a
   proper subgroup `H`, `BachSubgroupBound c` would give a unit `u ∉ H` with `u.val ≤ c log² m`;
   but `u` is one of the generators.
2. `BachCorollaries/EulerLiars.lean`: `eulerLiars n = {u : u^((n-1)/2) = (u/n)}` is a subgroup
   (`jacobiSym.mul_left`). It is proper for odd composite `n` (`eulerLiars_ne_top`): if `p² ∣ n`,
   `v = 1 + n/p` has `v^(n-1) = 1 − n/p ≠ 1` while every Euler liar has `u^(n-1) = (u/n)² = 1`;
   if `n = p m` with `p ∤ m`, `m > 2`, the CRT lift `k` of a non-residue mod `p` with `k ≡ 1
   (mod m)` has `(k/n) = −1` but `k^((n-1)/2) ≡ 1 (mod m)`.
3. `BachCorollaries/SolovayStrassen.lean`: Bach's bound gives a unit outside `eulerLiars n`;
   Euler's criterion (`legendreSym.eq_pow`) shows primes pass every base.
4. `BachCorollaries/Jacobi.lean` (`jacobiCalc_eq`): the binary Jacobi algorithm equals
   `jacobiSym` for odd `b` (second supplement `jacobiSym.even_odd`, reciprocity
   `jacobiSym.quadratic_reciprocity_if`).
5. `BachCorollaries/Test.lean` (`solovayStrassenTest_iff_prime`): bases `1 ≤ a ≤ min(n − 1,
   (⌊log₂ n⌋ + 1)²)`; `2 log² n ≤ (⌊log₂ n⌋ + 1)²` is miller-grh's
   `Miller.two_mul_log_sq_le_millerBound`, and `powMod` is miller-grh's.
6. `BachCorollaries/Factoring.lean`: `n = a b` with `a, b > 2` coprime; `r₀ < s` is the largest
   `r` with some `w^(2^r t) ≠ 1`, so every `y = u^(2^{r₀} t)` has `y² = 1`. The units with
   `y = ±1` form a proper subgroup (CRT), and outside it `y − 1` is neither `0` nor a unit, so
   the gcd is a proper factor.

## Deviations from the literature

* Generators: constant `2` instead of Bach's `3`, and `≤` instead of `<`. The `2` comes from
  lls-grh, whose `BachSubgroupBound 2` returns a unit prime to the modulus; Bach published that
  form (his Theorem 3) with `3`.
* Solovay–Strassen: the witness is prime to `n`; Bach's remark counts any witness.
* Miller's factoring is stated for odd `n` (for even `n`, `2` is a factor) and for any `M > 0`
  annihilating `(ℤ/n)ˣ`, which covers `λ(n)` and `φ(n)`. The factor is found at one exponent
  `2^{r₀} t`, `r₀ < s`, which depends on `n` and `M` but not on the base.

## Building

```
lake build                 # main library, standard axioms only, under three minutes
lake env lean Axioms.lean
```

Lean `v4.36.0`, Mathlib `fc4f59e5`. Requires ankeny-grh (only `Ankeny.Statement` is built,
which imports `Erdos985.Statement`), miller-grh (`Miller.Test` and its imports, no
`native_decide`) and lls-grh (only for `BachCorollaries/GRH.lean` and `Unconditional/`), all by
local path. The default target does not build lls-grh; `lake build BachCorollaries.GRH` builds
`LLS.Bach2.Main2`, with its 15 `native_decide` chunks (about 22 CPU-minutes) and lls-grh's other
dependencies.
