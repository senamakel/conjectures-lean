# Paper

`erdos985.tex` is the write-up of the proof; `erdos985.pdf` is the compiled version.

To rebuild the PDF, use [tectonic](https://tectonic-typesetting.github.io), which downloads the
LaTeX packages it needs:

```bash
cd paper
tectonic erdos985.tex
```

Any standard TeX distribution also works (`pdflatex erdos985.tex`, run twice for references).
