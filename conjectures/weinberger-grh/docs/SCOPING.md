## The route taken instead (idoneal numbers)

The class number formula and genus theory are not needed. The elementary definition gives
directly (`Weinberger/Elementary.lean`):

> `n = ab + bc + ca` iff `n + a² = (a + b)(a + c)`. If an odd prime `p ∤ n` with `p² < n` has
> `−n ≡ a² (mod p)`, take `1 ≤ a ≤ (p − 1)/2`, `u = p`, `v = (n + a²)/p`: then `2a < u < v`
> and `(a, u − a, v − a)` is a representation. So **an idoneal `n` has `(−n/p) = −1` for every
> odd prime `p ∤ n` below `√n`.**

That is a statement about the quadratic character of `ℚ(√−n)` at small primes, and GRH says
it cannot hold for large `n`: the weighted sum `Σ_{m<x} Λ(m)(1 − m/x)(1 + χ(m))` would be
`≈ x/2` (principal part) up to an error `≈ (2/3)√x log(4n)` (erdos-985's explicit formula and
GRH zero sum, re-assembled for an arbitrary primitive modulus), while the vanishing at primes
leaves only prime powers, primes `≤ √x` and primes dividing `2n`, at most `2(√x + 1 + ω(2n)) log x`.
With `x = ⌊√n⌋` this is contradictory once `n ≥ ~3·10^7`; we use `10^8`.

## Sizing

From a C and Python prototype (not kept in the repo):

- Analytic threshold with the provable bounds used in Lean
  (`#P ≤ √x + 1 + ω(2n)`, `ω(2n) ≤ log₂(2n)`, `log s ≤ s/100 + 3.8521`):
  margin first positive near `n ≈ 1.3·10^7` (with `#{p < √x} ≤ √x/2 + 1`) or `3.2·10^7` (with
  `≤ √x`). At `n = 10^8` the Lean inequality has margin 856 out of 5000.
- Finite check below `10^8`: for each `n`, search `u ∈ [3, 403)`, `a ∈ [1, (u−1)/2]` with
  `u ∣ n + a²` and `u² < n + a²`. In C: 8.6·10^8 inner steps, 1.7 s; the largest `u` needed is
  113 (at `n = 76740997`); exactly the 65 known numbers (and `0`) fail. In Lean `native_decide`:
  about 60 s per chunk of `10^7`, ten chunks in parallel.

The budget in the brief (a day of CPU on 95 cores) is not remotely approached: the whole
finite range costs about 10 CPU-minutes.

## Class number one (part B)

The same analytic step works, with a different elementary bridge: if `h(ℚ(√d)) = 1` and an
odd prime `p < |d|/4` splits, the prime above `p` is principal, generated by an integer of norm
`p`, but every non-rational integer of `ℚ(√d)` has norm at least `|d|/4`. The GRH half
(existence of a small split prime for `|d| ≥ 10^8`) is the same theorem as for part A. What is
missing from Mathlib is the bridge from `NumberField.classNumber (AdjoinRoot (X² − C d))` to
norms of elements:

1. identify `𝓞 (AdjoinRoot (X² − C d))` with `ℤ[√d]` or `ℤ[(1+√d)/2]`
   (`QuadraticAlgebra.Int.isIntegralClosure_iff` plus an `AdjoinRoot ≃ QuadraticAlgebra`
   isomorphism; estimated 300–600 lines);
2. for `p ∣ t² − d` (resp. `t² + t + (1−d)/4`), the ideal `(p, t + ω)` has absolute norm `p`;
   if it is principal, its generator has norm `±p` (`Ideal.absNorm_span_singleton`; estimated
   300–500 lines);
3. the easy direction, `h = 1` for the nine Heegner fields: Minkowski bound
   `(2/π)√|D| < 9` and inertness of the primes below it, via the `ClassNumber.lean` criteria
   (estimated 800–1500 lines, by comparison with `Cyclotomic/PID.lean`).

See `docs/BLUEPRINT.md` for how part B is assembled with these as named hypotheses.
