# Bach's sharp constant `2/log² 3` under GRH in Lean

Let `G(m)` be the least `y` such that the integers `a ≤ y` prime to `m` generate
`(ℤ/m)ˣ`; equivalently, every proper subgroup of `(ℤ/m)ˣ` misses a unit `a ≤ G(m)`. Bach
(*Explicit bounds for primality testing and related problems*, Math. Comp. 55 (1990) 355–380)
proves under GRH that every proper subgroup contains no run `1, …, x` of positive integers with
`x ≥ 2 log² m` (his Theorem 2) and, for integers prime to `m`, `x < 3 log² m` (Theorem 3).
At the end of his §6 he reports that computation allows `2/log² 3 = 1.657071…` in Theorem 2,
"which is the best possible constant. Possibly this is also true of Theorem 3, but no attempt has
been made to verify such a claim." The target here is that question: under GRH,
`G(m) ≤ (2/log² 3) log² m` for every `m ≥ 3`, with equality at `m = 3`.

This repository proves in Lean that `2/log² 3` cannot be lowered, and proves the bound with
that constant under GRH for every modulus `m < 2^17` (without GRH) and every `m ≥ 5·2^49`
(under GRH). For `2^17 ≤ m < 5·2^49` it proves the reduction "GRH and the bound on this range
give the bound for every `m`", and the constant `2` there (from lls-grh). The full statement
is not proved: `docs/PLAN.md` explains why and what closing the range costs.

**Status in the literature: RH-consequence (open in the sharp form).** The constant `2` for the
prime-to-`m` form is quoted by Bellotti (arXiv:2610.10177, 2026, §1) as Bach's and is proved in
Lean in [lls-grh](../lls-grh/) (`LLS.bach2_of_GRH`). Lamzouri–Li–Soundararajan (Math. Comp. 84
(2015), Thm 1.1) give `(log q + B(q))²` for `q ≥ 3000`, asymptotically constant `1`. The sharp
constant `2/log² 3` for the prime-to-`m` form was not found in the literature. Searched
2026-11-26: arXiv and the web (exa), MathOverflow ("How strong is this conjecture? (ℤ/nℤ)* is
generated by small elements"), Burthe (Acta Arith. 80 (1997)), Bach–Huelsbergen (Math. Comp. 61
(1993)), Bellotti (arXiv:2610.10177), Klurman–Shparlinski–Teräväinen (arXiv:2609.25393),
formal-conjectures, and the novelty audit `docs/atlas/sweeps/2026-11-26/novelty-audit.md`
(item c). Bach's paper was read through a search-engine copy of its text; the AMS page refused
the download.

## Main theorems

Statements, `BachSharp/Statement.lean` (fixed):

```lean
noncomputable def sharpConst : ℝ := 2 / Real.log 3 ^ 2
def SharpSubgroupBound : Prop := Ankeny.BachSubgroupBound sharpConst
def SharpGeneratorBound : Prop := BachCorollaries.GeneratorBound sharpConst
def SharpOptimal : Prop :=
  ∀ c : ℝ, c < sharpConst → ¬ Ankeny.BachSubgroupBound c ∧ ¬ BachCorollaries.GeneratorBound c
```

`Ankeny.BachSubgroupBound c` (ankeny-grh) is: for every `q` and every proper subgroup `H` of
`(ZMod q)ˣ` there is a unit `a ∉ H` with `a.val ≤ c log² q`. `BachCorollaries.GeneratorBound c`
(bach-corollaries-grh) is: `(ZMod m)ˣ` is generated by the classes of the positive integers
`≤ c log² m`.

Proved (`BachSharp/Optimal.lean`, `Small.lean`, `Large.lean`, `Main.lean`):

```lean
theorem BachSharp.sharpOptimal : SharpOptimal

theorem BachSharp.sharp_small (q : ℕ) [NeZero q] (hq : q < 2 ^ 17) (H : Subgroup (ZMod q)ˣ)
    (hH : H ≠ ⊤) : ∃ a : (ZMod q)ˣ, a ∉ H ∧ ((a : ZMod q).val : ℝ) ≤ sharpConst * Real.log q ^ 2

theorem BachSharp.sharp_large_of_GRH (hGRH : DirichletLNonvanishingRightOfHalf) (q : ℕ)
    [NeZero q] (hq : 5 * 2 ^ 49 ≤ q) (H : Subgroup (ZMod q)ˣ) (hH : H ≠ ⊤) :
    ∃ a : (ZMod q)ˣ, a ∉ H ∧ ((a : ZMod q).val : ℝ) ≤ sharpConst * Real.log q ^ 2

theorem BachSharp.sharp_outside_gap_of_GRH (hGRH : DirichletLNonvanishingRightOfHalf) (q : ℕ)
    [NeZero q] (hq : q < 2 ^ 17 ∨ 5 * 2 ^ 49 ≤ q) (H : Subgroup (ZMod q)ˣ) (hH : H ≠ ⊤) :
    ∃ a : (ZMod q)ˣ, a ∉ H ∧ ((a : ZMod q).val : ℝ) ≤ sharpConst * Real.log q ^ 2

theorem BachSharp.generators_outside_gap_of_GRH (hGRH : DirichletLNonvanishingRightOfHalf)
    (m : ℕ) [NeZero m] (hm : m < 2 ^ 17 ∨ 5 * 2 ^ 49 ≤ m) :
    Subgroup.closure {u : (ZMod m)ˣ |
      ∃ a : ℕ, 0 < a ∧ (a : ℝ) ≤ sharpConst * Real.log m ^ 2 ∧ (u : ZMod m) = a} = ⊤

theorem BachSharp.sharp_of_GRH_of_gap (hGRH : DirichletLNonvanishingRightOfHalf)
    (hgap : SharpGap) : SharpSubgroupBound ∧ SharpGeneratorBound

theorem BachSharp.bach_sharp_of_GRH (hGRH : DirichletLNonvanishingRightOfHalf) :
    Ankeny.BachSubgroupBound 2 ∧
    (∀ (q : ℕ) [NeZero q], (q < 2 ^ 17 ∨ 5 * 2 ^ 49 ≤ q) → ∀ H : Subgroup (ZMod q)ˣ, H ≠ ⊤ →
      ∃ a : (ZMod q)ˣ, a ∉ H ∧ ((a : ZMod q).val : ℝ) ≤ sharpConst * Real.log q ^ 2) ∧
    SharpOptimal
```

`SharpGap` (`Main.lean`) is the sharp subgroup bound for `2^17 ≤ q < 5·2^49`.
`sharp_large_of_GRH` comes from `bach1657_large_of_GRH`, the bound with the constant
`1657/1000 ≤ 2/log² 3`.

## Proof outline

1. **Optimality** (`Optimal.lean`). `(ZMod 3)ˣ = {1, 2}` and `sharpConst · log² 3 = 2`; for
   `c < sharpConst` the trivial subgroup misses no unit `≤ c log² 3 < 2`, and only the class
   `1` is a positive integer `≤ c log² 3`.
2. **Small moduli** (`Small.lean`). `m = 3` by hand (equality); `4 ≤ m < 2^17` by search.
   Only `m = 3` needs the full constant: with `1.657` every other `m < 2^17` passes.
3. **The GRH budget** (`Sound.lean`). lls-grh's inequality `base2(x, Pc) − κ(x) log q − C(q) ≤ 0`
   for a character trivial on `H` and on every `n ≤ x` prime to `q` (`LLS.budget_nonpos`),
   applied at `x = ⌊(cn/cd) log² q⌋`. `checkChunkC` is lls-grh's `checkChunk` with `2`
   replaced by `cn/cd`; its soundness proof is lls-grh's with the same replacement.
4. **The tail** (`Tail.lean`). `goodQ_tailS : 2^7400 ≤ q → GoodQ (1657/1000) q`, lls-grh's
   polynomial argument with `L ≤ 0.7769(√x + 1)` (`0.7769² · 1.657 > 1`) and `x^{1/8} ≥ 9`.
5. **Assembly** (`Large.lean`, `Main.lean`); `1657/1000 ≤ 2/log² 3` from Mathlib's
   `Real.log_three_lt_d9`.

## Why the range `2^17 ≤ m < 5·2^49` is open

Details and numbers in [`docs/PLAN.md`](docs/PLAN.md). At `c = 1.657` the GRH budget fails for
moduli with many small prime factors up to about `10^13.2` (about `1.25·10^6` of them,
`Σ q ≈ 6·10^15`), and the cheap uniform test only from `2^51.3`. The existing checker would
have to loop over every modulus below `2^51` and run a breadth-first search over each failing
`(ℤ/q)ˣ`: out of reach. Closing the range needs a block checker that enumerates the costly
smooth kernels instead of moduli, and a structural generation certificate (factorisation,
primitive roots, a Frattini rank test per prime `ℓ | φ(q)`) for the failing moduli, each with a
soundness proof. Numerically the statement holds: `G(m) ≤ (2/log² 3) log² m` for every
`3 ≤ m ≤ 10^7`, with equality only at `m = 3`; the next ratios are 1.561 (`m = 4`), 1.557
(`6`), 1.287 (`24`), and for `m ≥ 25` the ratio stays below 1.053 (`m = 70`).
