# Blueprint: the exponent `21/5` (Rosser's sieve with a checked table)

## What Shoup's proof uses

Shoup (Math. Comp. 58 (1992), Thm 1.3) omits the sieve details; G. Martin, *The least prime
primitive root and the shifted sieve*, Acta Arith. 80 (1997), §3 (arXiv:math/9807104) gives
them. Martin's Lemma 7 is Iwaniec's shifted sieve (Demonstratio Math. 11 (1978), Lemma 1): send
the `r` primes of `Υ = rad(p − 1)`, in increasing order, to the first `r` primes
`p_1 < … < p_r` (`p_j ≤ q_j`), take Rosser's lower weights `λ_d` for `P = p_1 ⋯ p_r` at level
`y = C z²` (`z = p_r ≍ r log r`), and use that `Σ_e λ_e/g(e) = ∏(1 − 1/g) Σ_d σ_d ∏_{p|d} 1/(g(p)−1)`
is monotone in `g` because `σ_d = Σ_{e|d} λ_e ≤ 0` for `d > 1`. Iwaniec's Lemma 2 supplies
`Σ |λ_d| ≪ y/(log y)²` and `Σ σ_d/φ(d) = f(s) + O(1/log y)` with `f(s) = 2e^γ log(s−1)/s`.
So the main term is `≫ ∏(1 − 1/q)/log z` and the mass `≪ z²/(log z)²`, giving
`x ≪ (r² log² r)² log² p`.

The two inputs that make Shoup's `(log r)^4` possible are the error `O(1/log y)` at the edge
`s = 2 + O(1/log z)` and the mass saving `(log y)^{-2}`. Neither is formalised here.

## What is formalised instead

Rosser's sieve at a *fixed* level exponent `s₀ = 2.05`, for any finite set `Q` of primes above
`w₀ = 2^{2^{36}}`:

1. **Weights** (`Rosser/Defs.lean`). `L(Q,Y) = 1 − Σ_{p∈Q} y_p U(Q_{<p}, Y/p)`,
   `U(Q,Y) = 1 − Σ_{p∈Q, p^{3.1}<Y} y_p L(Q_{<p}, Y/p)`. On `0/1` points `L ≤ 0` unless all
   `y = 0`, and `U ≥ 0` (any choice of kept primes works for `U`). The upper cut is `3.1`
   rather than Rosser's `3`: then `U` only uses lower bounds at `s > 2.1`, where they are
   positive with margin. With the cut at `3`, the discretised system is critical at `s = 2`
   (the true `(1 − f, F − 1)` is an eigenvector with eigenvalue 1) and no table exists.
2. **Mass** (`Rosser/Defs.lean`). Every monomial of `L(Q,Y)` is a distinct squarefree
   `d ≤ Y` when `q² < Y` for `q ∈ Q`, so the mass is `≤ Y`.
3. **Steps** (`Rosser/Layer.lean`). With `V(Q) = ∏(1 − 1/q)`, `W(p) = ∏_{q≥p}(1 − 1/q)^{-1}`:
   `L = V(1 − Σ_p (1/p) W(p) h_p)` and `U = V(1 + Σ_p (1/p) W(p) h'_p)`, where `h_p` is the
   excess of the inner bound. Over the primes with `u_p = log z/log p ≤ t`,
   `Σ (1/p)W(p) = ∏(1 − 1/q)^{-1} − 1 ≤ Ω(t) − 1`, `Ω(t) = 1.001 t (1 + (t−1)/1000)`
   (`Rosser/Mertens.lean`, from the block bound `sigma_block_le` chained over `(2^lo, 2^{4lo}]`).
   A layer cake over a decreasing step majorant of `h` in `u_p`, plus a dyadic tail, bounds
   the sum (`row_bound`).
4. **Table** (`Rosser/Table.lean`, generated by `scripts/rosser/`). 232 grid cells
   `s = g/100` (step `0.02` on `[1,2)`, `0.01` on `[2,3)`, `0.02` on `[3,4)`, `0.1` on `[4,6)`,
   `0.5` on `[6,12)`), each with `β` (`U ≤ V(1+β)` for `s ≥ g/100`) and, for `g ≥ 200`, `α`
   (`L ≥ V(1−α)`); for `s ≥ 12` the bounds `V(1 ± s^{-6})`. The values come from a linear
   program; every row inequality, in fixed point `2^{-48}` rounded up, is checked by one kernel
   `decide` (`allOK_cells`, about 60 s). Smallest row margin `9·10^{-7}`; the tail rows reach
   `0.984 ≤ 1`.
5. **Induction** (`Rosser/Claims.lean`). All bounds hold for all `Q`, by induction on `|Q|`:
   each row of the table is exactly the inequality the next step needs.
6. **Assembly** (`PolyReal.lean`). `Z = A^{32} r^{1.01}` (`A = 2^E`), `Y = Z^{2.05}`;
   exact sieve on primes `≤ A`, Rosser on `(A, Z)`, union bound on primes `≥ Z`. The table gives
   `α_{2.05} ≤ 0.98`, so the main term is `≥ 1/(200(A+1)t²)` with `t = log Z/log A`; the mass is
   `≤ (2^{2^E}+1) Y`; `x ≤ 1089 (M log p/θ)² ≪ (Z^{2.05} (log Z)²)² log² p ≪ r^{4.2} log² p`.

## Numbers

| Route | mass exponent `s` | exponent `2s` |
|---|---|---|
| Brun–Hooley, one level (exponent 7 theorem) | 3.384 | 6.77 |
| Buchstab + Brun–Hooley uppers (Wang's 6) | 2.998 | 5.996 |
| Rosser recursion, this table, zero of `α` | ≈ 2.025 | ≈ 4.05 |
| Rosser recursion, used (`a(2.05) ≥ 0.02`) | 2.05 (× 1.01 for `Z`, + logs) | 4.2 |
| Shoup / Martin (linear sieve to `s = 2 + O(1/log z)`) | 2 + o(1) | `4`, with `(log r)^4` |

Table values against the linear sieve functions (`F(s) = 2e^γ/s` on `[1,3]`,
`f(s) = 2e^γ log(s−1)/s` on `[2,4]`): `b(1) ≈ 3.68` (`F = 3.56`), `b(2) ≈ 1.81` (`1.78`),
`a(2.1) ≈ 0.11` (`0.16`), `a(2.2) ≈ 0.25` (`0.30`), `a(3) ≈ 0.81` (`0.82`).

## What `ShoupStatement` still needs

`ω⁴(log ω + 1)⁴` requires `s → 2` as `z → ∞`, with the zero of the lower function at
distance `O(1/log z)` from 2: an analysis with errors `O(1/log y)` uniform in `z` (Iwaniec's
Lemma 2, i.e. the Jurkat–Richert/Iwaniec theory with the functions `F`, `f`), plus the mass
bound `Σ|λ_d| ≪ y/(log y)²`. A fixed table can only reach a fixed `s₀ > 2`. With this grid the
lower function vanishes near `2.025`; a finer grid should move that zero towards `2` (not
tried), which would give `PolyOmegaRealStatement (4 + ε)` for a given `ε`, never the
logarithmic form.
